# Plans

Deferred and in-progress plans, one `<topic>.md` each. A plan is a proposal, not a
decision — when it is taken, the reasoning moves to [`docs/decisions.md`](../docs/decisions.md)
in the same commit as the change.

**When a plan is executed completely, delete it.** If it was only partly executed, ask the
owner whether to keep, trim, or delete it; never leave one that reads as open when it is
mostly done. Finished plans are not archived here — `docs/history/` holds the one
exception and stays at one file. The rule lives in [`CLAUDE.md`](../CLAUDE.md).
