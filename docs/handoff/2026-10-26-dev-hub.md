   b. **On zero** (`ssh zero`, fish), the one profile left and the new volumes:
      ```fish
      cd ~/infra; and git pull --ff-only
      install -m 600 dev/.env ~/dev.env.before-rename
      grep ^COMPOSE_PROFILES= dev/.env
      sed -i 's/^COMPOSE_PROFILES=.*/COMPOSE_PROFILES=tunnel/' dev/.env
      grep ^COMPOSE_PROFILES= dev/.env
      make -C dev check
      ```
      The line should read `COMPOSE_PROFILES=tunnel` (it was probably `tunnel,or3-dev`).
      `make check` refuses any other name now, since no repo's container has a profile. It then names any missing external volume: they must all
      begin `invective-dev_`, `nibbles-dev_`, `ionic-dev_` or `claude-sessions_`. If any other
      is missing, stop: a name in compose.yaml is wrong. If not, `make -C dev volumes` makes
      them, and `make -C dev check` passes. Then build every image, one at a time. A build
      touches no container, and it makes step c's build a cache hit:
      ```fish
      for s in hub infra or3 destiny-director dossier invective nibbles ionic-traces claude-sessions; make -C ~/infra/dev build S=$s; or break; end
      ```
      If one fails, the loop stops at it and nothing has changed; tell infra's agent which.

      `cd ~/infra; git pull --ff-only; cd ansible; ansible-playbook playbooks/server-deploy-compose.yml -e deployment=dev -K`.
